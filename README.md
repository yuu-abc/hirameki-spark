# ひらめきスパーク

**その一押しで、主役になれ。**

ひらめいた瞬間にボタンを押して、CPUと競う早押しクイズ。スマホでもパソコンでも、クイズ番組のような早押し対戦をひとりで楽しめます。

[ひらめきスパークで遊ぶ](https://yuu-abc.github.io/hirameki-spark/)

## モードを選ぶ

- **早押しクイズ**：少しずつ表示される問題文を読んで、答えがわかったら早押し。
- **早押し連想**：順番に出るヒントから、人物や、複数の言葉に共通する文字をひらめこう。

## 遊び方

- モードと対戦相手を選びます。相手によって、問題の難しさとCPUの強さが変わります。
- わかったら「早押し！」をタップ。パソコンではスペースキーでも押せます。
- 回答権を取ったら、制限時間内に選択肢から答えを選びます。正解で加点、お手つきや回答時間切れで減点。お手つきのあとは相手に回答のチャンスがあります。

## 正解・解説と根拠資料

回答後の解説や対戦結果の振り返りから、正解の根拠となる資料を確認できます。資料は別タブで開くので、読み終えたら元のクイズのタブに戻ってください。
