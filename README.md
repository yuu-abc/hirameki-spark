# ひらめきスパーク

「わかった！」と思った瞬間に早押し。CPUの「ピコ」と得点を競う、ブラウザで遊べる1人用クイズゲームです。

## 🎮 遊ぶ

**[ひらめきスパークを開く](https://yuu-abc.github.io/hirameki-spark/)**

スマートフォンやパソコンのブラウザから遊べます。アカウント登録やアプリのインストールは不要です。

## 収録内容

合計 **650問** を収録しています。

| モード | 問題数 | 遊び方 |
| --- | ---: | --- |
| 早押しクイズ | 500問 | 少しずつ表示される問題文を読んで早押し |
| 早押し連想 | 150問 | 3×3の9マスに開く短いヒントから答えを推理 |

早押しクイズは、ことば・世界・日本・科学・自然・歴史・文化・スポーツ・漫画・アニメ・映画・数学・地理・英語の **14ジャンル**。問題は自動で選ばれます。

「〜ですが、〇〇は？」と途中で問いが変わる問題もあるので、早く押すだけでなく、何を聞かれているか見極めるのがポイントです。

## 基本の遊び方

1. モード、対戦相手、1試合の問題数を選びます。
2. 「対戦スタート」を押します。
3. 答えがわかったら、黄色い「早押し！」を押します。
4. 先に押した側が回答権を獲得。表示された4つの選択肢から、**8秒以内**に答えます。
5. 正解と解説を確認して、次の問題へ進みます。

選択肢は早押しするまで表示されません。回答中は問題文やヒントの進行が止まります。

### 得点と勝敗

- 正解：**＋10点**
- 誤答・回答時間切れ：**−5点**
- お手つき後は相手に回答チャンスが移ります。同じ問題で再回答はできません。
- 両者とも誤答した場合や、受付時間内に誰も正解しなかった場合は、その問題が終了します。
- 最後に得点が高い方の勝ち。同点は引き分けです。
- 1試合の中で同じ問題は重複しません。

試合終了後は、正答率・平均早押しタイム・お手つき回数を確認できます。「今回の問題をふりかえる」から、答えと解説を読み直せます。

## 早押し連想のルール

- ヒントは **3×3の9マス**。左上から右へ、上の段から順番に開きます。
- 最初の1マスから早押しでき、以後は **2.4秒ごと**に1マスずつ公開されます。
- 公開済みのヒントは残ります。青い「？」は未公開のマスです。
- 最後のヒントが開いてから **6.5秒**で早押しの受付が終了します。
- お手つき後は残りのヒントが続き、相手にも最低6.5秒の猶予があります。
- どの対戦相手でも難度を混ぜて出題します。相手によってCPUの速さ・慎重さ・正答率が変わります。

## 対戦設定

CPUは3段階、1試合の問題数は **5問・10問・15問**から選べます。

| 対戦相手 | 早押しクイズの出題 | CPUの特徴 |
| --- | --- | --- |
| のんびり ピコ | 基本中心 | ゆっくり、慎重に挑戦 |
| 本気の ピコ | 標準＋難問 | 本格的な勝負 |
| 覚醒 ピコ | 難問のみ | 素早い早押し |

CPUにも間違いや見送りがあります。連想モードでは、公開されたヒントに応じて回答を判断します。

## 操作

スマートフォンでは画面のボタンをタップします。パソコンではクリックに加えて、次のキーも使えます。

| キー | 操作 |
| --- | --- |
| Space | 出題中に早押し |
| 1〜4 | 回答権を取った後、対応する選択肢を選ぶ |
| Enter | 正解・解説画面から次へ進む |
| Esc | 対戦中に一時停止。一時停止中は再開 |

画面の「一時停止」ボタンも使えます。別のタブやアプリに移ったときは自動で一時停止します。

## 音と保存

- 「音 ON／OFF」で、BGMと効果音をまとめて切り替えられます。
- 「番組サウンド」では、BGMだけのON／OFFと音量を調整できます。
- 音が出ないときは、画面を操作してから、ゲームの音設定と端末側の音量を確認してください。
- 設定・累積成績・最近出題した問題の履歴は、そのブラウザ内に保存されます。
- 別の端末やブラウザには自動で引き継がれません。ブラウザのデータを削除すると記録も消えます。
- 保存が利用できない環境でもプレイできます。対戦を途中でやめた場合、その試合は累積成績に記録されません。

## ダウンロードして遊ぶ

ゲーム本体は **index.html 1ファイル**です。問題・画像・音声をファイル内に含み、プレイ中に追加データをダウンロードする必要はありません。
